# API

## Setup
```bash
npm install
cp .env.example .env
npm run dev
```

Windows PowerShell:
```powershell
Copy-Item .env.example .env
```

## Example API
- `GET /api/health`
- `POST /api/auth/register`
- `POST /api/auth/login`
- `GET /api/contacts`
- `POST /api/contacts`
- `GET /api/tickets`
- `POST /api/tickets`
- `GET /api/conversations`
- `POST /api/conversations`
- `POST /api/ai/tool-call`
- `GET /api/webhooks/whatsapp`
- `POST /api/webhooks/whatsapp`
